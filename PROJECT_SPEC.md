# Project Specification

## Project Name
Quantum Sensing Earth MVP

## Problem
Earth observation systems need better measurement fidelity for hydrology, groundwater, ice mass, and climate-risk intelligence.

## MVP Hypothesis
If a simulated quantum-enhanced gravity sensor has lower noise, better spatial resolution, and lower drift than a classical profile, anomaly detection on groundwater-like mass changes should improve under benchmarked conditions.

## Algorithms Used
- Gaussian field synthesis: procedural simulation
- Z-score thresholding: statistical anomaly detection
- Isolation Forest: tree-based unsupervised anomaly detection
- DBSCAN: density-based spatial clustering
- RMSE/SNR/F1 metrics: benchmark evaluation
